# プライバシーポリシー / Privacy Policy — あんきカード (Flash Cards)
## 日本語
本拡張機能は個人情報を一切収集・送信しません。カード、デッキ、学習状態、Premium 状態は chrome.storage.local 内にのみ保存されます。拡張機能はバックグラウンドで外部サーバーへデータを送信しません。ユーザーが購入ボタンを押した場合のみ、支払い手続きのため Stripe Checkout の外部ページを開きます。トラッキング・広告・第三者提供はありません。拡張機能を削除すると保存データも削除されます。
## English
This extension collects/transmits no personal data. Cards, decks, study state, and Premium state are stored only in chrome.storage.local. The extension does not send data to external servers in the background. Only when the user clicks the purchase button, it opens an external Stripe Checkout page for payment. No tracking, ads, or sharing. Uninstalling removes all stored data.
